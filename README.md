# My Snippets 🚀

Building this app was part of my React practice to level up my skills. Instead of just making a basic to-do app, I built an algorithmic flashcard and code snippet manager where I can save DSA concepts, code snippets, and difficulties. 

## What’s Inside This App?

* **Component Architecture:** Broken down into clean, reusable components like `Header`, `CardForm`, and `FlashcardList`.
* **Props & State Management:** Passing state up and down smoothly between components without breaking a sweat, using `useState` and `useEffect` entirely from memory.
* **Dynamic Rendering & Filtering:** Maps through cards dynamically, handles empty states, and features a real-time search bar using modern array methods (`.filter()`, `.map()`).
* **Data Persistence:** Integrated `localStorage` so your snippets don't vanish when you refresh the page.
* **Full CRUD Functionality:** Add new algorithmic snippets with custom difficulty badges (Easy, Medium, Hard) and delete them when you're done.
* **Custom Dark Theme & Responsive UI:** Designed with a sleek midnight slate palette, CSS Grid, and custom media queries so it works nicely on desktop and mobile.
